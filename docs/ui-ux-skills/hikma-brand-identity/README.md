# Hikma Brand Identity

La marque Hikma repose sur une présence calme, éditoriale et attentive. Le système associe un teal profond, un or chaud, des surfaces ivoire/crème et un charbon lisible. La couleur accompagne la compréhension ; elle ne remplace ni la hiérarchie ni le feedback pédagogique.

## Principes

- Utiliser les tokens `--hikma-*` et leurs classes Tailwind correspondantes plutôt que des hexadécimaux dans les composants.
- Réserver l’or aux accents, repères et détails premium. Il ne porte pas seul un long texte courant.
- Conserver les couleurs fonctionnelles (`success`, `error`, `warning`, `info`) pour que les états d’apprentissage restent immédiatement compréhensibles.
- Préserver l’arabe et ses diacritiques dans un bloc RTL local ; ne jamais appliquer le RTL à toute la page pour aligner un mot.
- Garder une interface claire en mode clair comme en mode sombre, avec des surfaces et bordures dédiées.
