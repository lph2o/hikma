# Exemples

## Découverte

`Mot 2 sur 5` → arabe → translittération → écouter → `Voir le sens` → `Mot suivant`.

## Exercice

`Tu apprends à reconnaître le sens` → consigne → options → `Valider` → feedback → `Continuer`.

## Exercise Shell

`HikmaExerciseShell` garde cette structure pour les QCM, le rappel libre, l’audio et la phonétique. Seule la zone d’interaction change ; le shell ne reçoit aucune responsabilité de validation.

## Options

L’ordre visuel est dérivé d’un seed stable de l’exercice. Un même exercice conserve son ordre pendant son rendu, tandis que deux exercices peuvent placer la bonne réponse à des endroits différents.

## Fin

Résumé réel de la session → `Continuer le parcours` → `Revoir` en action secondaire.
