# Responsive

La priorité est mobile à 320 px : contenu mono-colonne, arabe lisible, boutons pleine largeur et footer d’action facilement atteignable. À partir de 640 px, on augmente l’espace et la largeur de lecture sans transformer la session en grille. À 1440 px, la colonne reste volontairement limitée pour préserver le focus.

Le shell conserve la même largeur et le même ordre vertical sur mobile : progression, compétence, interaction, feedback, puis CTA. Les réponses utilisent des cibles `min-h-12` et le footer passe en pleine largeur avant `sm`.
